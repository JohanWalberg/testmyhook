05 / How to use
>TestMyHook

How to use

Open the site and you already have a live URL. Use it to see what a service sends before you build the real receiver on your own site.

STEP 01
Copy your URL

Every URL gets its own random slug. Open as many as you need and switch between them with tabs.

STEP 02
Send a request

Webhooks arrive as POST, but any method works. Requests appear in the sidebar within a second.

STEP 03
Inspect and reply

Read headers, body and query params. Set the status code and body we send back to the sender.

CURL
$ curl -X POST \
https://testmyhook.dev/tiny-snow-27/orders \
-d '{"hello":"world"}'
JAVASCRIPT
await fetch("https://testmyhook.dev
/tiny-snow-27/orders", {
method: "POST", body: json
})
Retention
URLs are deleted after 7 days of inactivity.
Limits
100 webhooks kept per URL · 1 MB body max.
Accounts
None. The site is open to everyone.
